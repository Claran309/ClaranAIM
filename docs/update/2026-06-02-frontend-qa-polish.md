# 2026-06-02 前端 QA 与交互修补

## 检查范围

本轮重点复查前端构建文件是否存在按钮不可用、接口不对接、悬浮窗错位、弹窗滚动混乱和 Markdown 渲染撑开布局等问题。

## 修复内容

- 补齐 CSS 变量 `--muted`，避免记忆卡片、说明文字等使用未定义颜色变量。
- 修复 Skill 列表“复制目录”按钮缺少 `copyText` 函数的问题。
- 优化 Agent 管理二级菜单：
  - 点击菜单项后自动关闭。
  - 打开弹窗前主动关闭菜单，避免菜单覆盖 modal。
  - 刷新 Agent 列表前清理已经移动到 `body` 下的旧菜单节点。
  - 菜单增加最大宽高和内部滚动，贴近屏幕边缘时不再溢出。
- 优化弹窗滚动：
  - modal 外层不再整体滚动，改为正文区域滚动。
  - 打开新弹窗或返回上一层弹窗时重置滚动位置。
  - Agent 运行弹窗的正文不滚动，由内部历史消息区域滚动，减少双滚动。
- 优化 Markdown 表格和代码块：
  - 表格和代码块最大宽度改为容器宽度，避免撑爆聊天气泡或 Agent 对话气泡。
  - 表格继续保留横向滚动，长表格不会压坏布局。
- 优化小屏 Agent 运行窗口：
  - 去掉过高的固定最小高度，避免手机窄屏下弹窗挤出视口。

## 对接检查

- 前端新增功能 API 与 `api-gateway` 路由已复核：
  - Agent、Memory、RAG、Knowledge、Settings、MCP、Admin、Web Search、Conversation Intelligence 均有对应网关路由。
  - 登录、注册和刷新 Token 属于 public 路由，未放在 auth 组内是预期行为。
- 静态扫描了前端 `onclick` 调用，确认 176 个直接按钮函数均存在。
