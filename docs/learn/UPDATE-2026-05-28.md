# 2026-05-28 重新扫描更新记录

本文件记录本次重新扫描项目后，`learn/` 学习资料相对上一版更新了什么。

## 总体变化

项目已经从上一版的 `bot-manager-service` 表述进一步迁移到 Agent 语义：

- 服务目录使用 `agent-manager-service`。
- 服务目录使用 `agent-runtime-service`。
- HTTP 对外入口统一为 `/agent/*`。
- 旧 `/bot/*` HTTP 兼容入口已移除。
- 但历史 IDL、生成代码和数据库表仍保留 `bot` 命名，例如 `bot.thrift`、`kitex_gen/bot`、`bots`。

学习资料已按“对外 Agent、底层兼容 bot 命名”的方式重写。

## 新增服务纳入课程

本次把这些服务纳入主线：

- `memory-service`：`memory_facts`，支持用户/群/会话/session 记忆治理。
- `settings-service`：LLM 预设和 Prompt 模板。
- `msg-history-service`：历史消息拆分方向。
- `file-service`：文件元数据服务。
- `msg-filter-service`：审核/过滤预留服务。

并补充：

- 网关现在同时调用 Kitex RPC 和内部 HTTP client。
- 分页参数统一校验并限制最大 limit。
- 非负游标/ID 查询参数会返回明确 400。

## 用户与好友变化

lesson2 已更新：

- 登录更新在线状态失败不再被忽略。
- 添加好友时，如果反向好友关系写入失败，会回滚正向关系。
- 删除好友时，如果反向删除失败，会返回错误。

这让好友双向关系的一致性更清晰。

## 前端体验变化

lesson6 和相关概览已更新：

- 好友列表支持分组折叠状态。
- 消息渲染增加基于 `id/msg_id/client_msg_id` 的去重。
- Markdown 渲染支持表格。
- Agent 返回 JSON 字符串或 fenced json 时可解析。
- Action Card 识别字段扩展：`cards`、`action_cards`、`actionCards`、`action_decisions`、`decisions`、`actions`。

## Agent-native 内容变化

仍保留并强化上一版内容：

- `claran.im.events`
- `IMEventPayload`
- `agent_subscription_rules`
- `agent_audit_records`
- `agent_dispatch_records`
- Agent Event Dispatcher 双 topic 消费
- `record` / `trigger`
- `idempotency_key` 优先作为业务幂等键
- Agent 回复使用 `client_msg_id=agent:{dispatch_key}:{agent_user_id}`
